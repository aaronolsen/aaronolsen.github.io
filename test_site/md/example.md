### Code Blocks and Tables

You can format `inline code` by wrapping it in single backticks. 

For longer blocks, use triple backticks (fences) and specify the programming language for syntax highlighting:

```python
def greet(name):
    # Print a welcome message
    print(f"Hello, {name}!")
```
